# 媒体素材命名规则

## 文件夹建议

- `media/products/`
- `media/suppliers/`
- `media/projects/`
- `media/raw/`

## 命名格式

建议使用英文小写、短横线分隔：

`product-category-model-view-date-number.ext`

示例：

- `water-well-rig-xy100-main-2026-001.jpg`
- `drill-pipe-76mm-thread-detail-2026-001.jpg`
- `dth-bit-115mm-front-2026-001.png`

## 命名规则

- 不使用中文文件名。
- 不使用空格。
- 不使用 `new`、`final`、`best` 等含义不清的词。
- 原始素材先放入 `media/raw/`，整理后再移动到对应分类。
- 客户或供应商敏感资料不要公开上传，除非确认可以公开使用。
