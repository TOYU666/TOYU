# 参数整理规则

## 总原则

- 参数必须准确、可追溯。
- 不确定的参数统一写 `待确认`。
- 不要为了完整性编造数据。
- 不同型号、不同配置和不同供应商的参数要分开记录。

## 参数来源优先级

1. 供应商正式参数表
2. 产品铭牌或说明书
3. 报价单或合同资料
4. 供应商聊天确认记录
5. 历史成交或发货记录

## 记录格式

| Parameter | Value | Source | Status |
| --- | --- | --- | --- |
| Model | 待确认 | 待确认 | 待确认 |

## 注意事项

- 单位必须写清楚，例如 m、mm、kW、MPa。
- 英文页面里的参数名称要保持一致。
- 参数更新时注明来源和日期。
