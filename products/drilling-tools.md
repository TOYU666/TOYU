# Drilling Tools

## 中文说明

钻具资料页用于整理钻头、冲击器、接头、扩孔器和其他钻进工具。

## 英文文案草稿

Drilling tools should be selected according to rig type, drilling method, hole diameter, rock hardness, air pressure, and site conditions. Correct matching helps improve drilling efficiency and reduce unnecessary wear.

## 常见产品

- DTH hammer
- DTH bits
- Tricone bits
- Drag bits
- Adapters
- Reamers
